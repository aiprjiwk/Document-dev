# Templates Directory

Place your Excel master templates (e.g. `Adjustment_Template.xlsx` containing the `"Master"` sheet) here.

The template Excel must include:
* **Sheet Name**: `"Master"`
* **Column B**: German labels (e.g. `Roboterkwerkzeug`, `Bau-Nr.`)
* **Column D**: English labels (e.g. `Robot tool`, `Serial-no.`)
* **Value Columns**: Writable columns (e.g. `E`, `F`, `G`, `H`, `I` etc.) where the system writes back verified values.
