# IQOQDQ Data Directory

This directory is dedicated exclusively for all **IQOQDQ Qualification Data**, raw specifications, test templates, and input files.

## 📁 Directory Structure:
- `IQ_Installation/` : Installation checklists, utilities, technical specifications, and setup documents.
- `IQ_Safety/` : Safety circuits, guarding, interlocks, emergency stop verifications.
- `IQ_Format/` : Format parts, tooling dimensions, carton/product specs, changeovers.
- `OQ_Operational/` : Operational qualification test data, station sequences, alarms, and reject tests.
