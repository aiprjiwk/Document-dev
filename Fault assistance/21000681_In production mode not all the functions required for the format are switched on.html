In production mode not all the functions required for the format are switched on
Effect on machine operation:
    ▪
    The machine cannot be started
Under the individual machine functions, you can define which of these are required for the current format. If a machine function has been identified as required, this must also be activated in operation.
Cause
Elimination
The machine is to be started in production operation and one or more machine functions have been identified as "Required in format", even though they are not required for the format.
    ▪
    Under the corresponding machine functions, deactivate the checkbox {Required in the format}.
The switch for the corresponding machine function flashes red in operation.
