21000304_Manual switching on/off of outputs is activated
Effect on machine operation:
    ▪
    The machine cannot be started
Cause
Elimination
On the touchscreen, register {IO-View} was switched to and the write function was activated using the switch {Activate}.
After completing work in the I/O display:
    ▪
    Deactivate the write function by pressing the switch {Activate}.
    ▪
    Exit the register {IO-View}.
CAUTION
Manual setting of output conditions
Manual setting and associated manual modification of output conditions may trigger undesired machine reactions (collisions overheating, etc.).
It is essential to assess and consider all possible consequences before forcing any output conditions.
Output conditions may only be overwritten if the consequences of the modifications are known and cannot result in any damage or danger.
CAUTION
Activating the write function
Activating the write function stops the PLC program so that it can no longer be processed.
