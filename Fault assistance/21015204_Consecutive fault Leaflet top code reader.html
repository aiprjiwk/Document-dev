Consecutive fault Leaflet top code reader
Effect on machine operation:
    ▪
    Homerun stop once number of consecutive faults is reached
The machine only shuts down once the preset number of consecutive faults has been reached.
The machine ends the current movements and then remains in the home position. Several cycles may be required until the current movements are ended and the machine stops, if the process requires it.
Cause
Elimination
The entered reference code is incorrect.
    ▪
    Correct the entered reference code.
The adjustment for the consecutive fault is too small.
    ▪
    Change the value for the consecutive fault on the touchscreen under the associated machine function.
Incorrect leaflet are being used.
    ▪
    Check the leaflet.
Leaflet are damaged during transport or in the infeed.
    ▪
    Monitor the transport route.
    ▪
    Monitor the carton infeed.
    ▪
    Monitor the adjustment of the guide.
The setting for consecutive faults is too low.
    ▪
    Change the value for consecutive faults under the respective machine function on the touchscreen.
The code scanner optics is soiled.
    ▪
    Clean the code scanner.
The code scanner is defective or adjusted incorrectly.
    ▪
    Check code scanner function and setting.
Wire break in cabling.
    ▪
    Check the cabling of individual parts.
