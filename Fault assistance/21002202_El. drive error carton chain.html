El. drive error carton chain
Effect on machine operation:
    ▪
    Immediate Stop
The machine is stopped immediately.
If a reference run is required after fault elimination and before the machine is restarted, or if products or packaging material need to be removed, this is indicated on the screen.
Possible causes:
    ▪
    Fault in the power supply to the drive
    ▪
    Fault in the drive controller
    ▪
    Fault in the drive
To eliminate faults, proceed in the following sequence:
Switch to the register {PLC diagnosis} in the menu {DIAGNOSIS}.
A mask with the PLC diagnostic data appears.
Read out and note current diagnostic data.
Implement the required fault elimination measures.
Eliminate the fault by following instructions in the programming manual of the drive controls.
NOTE
For the fault code, there is a fault message in the programming manual of the drive controls. The respective fault message as well as possible causes and their elimination are described in more detail in the manual.
Reset the fault using the Reset button.
If the fault cannot be eliminated, switch the machine off and on again.
Reset the fault using the Reset button.
If the fault cannot be eliminated, contact the IWK Service Department.
